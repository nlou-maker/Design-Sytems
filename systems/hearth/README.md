# Hearth Design System

Original design system for Healthy with Naudia. Warm terracotta-and-oat palette, Fraunces + Work Sans typography. Inspired by the mood of `references/luffu/` (warm, editorial, family-centered) — built with entirely original tokens, type, and layout. See that folder's `NOT_MY_BRAND.md` for why nothing here is copied from it.

See [DESIGN.md](./DESIGN.md) for full brand guidelines.

## Colors

| Name | Value | Role |
|------|-------|------|
| Ember | `#9A4B32` | Primary CTA, links, accents |
| Oat | `#F7F2E7` | Page background |
| Sand | `#EDE4D3` | Section alternation |
| Clay | `#DCC9AE` | Card surfaces |
| Bark | `#2E2A24` | Primary text |
| Stone | `#6B6259` | Secondary text |
| Moss | `#4A4038` | Tertiary text |

## Typography

- **Fraunces** — display headings, wordmark (600 weight)
- **Work Sans** — body, nav, buttons (400/500 weight)

Both free, self-hosted, SIL Open Font License via Google Fonts.

## Components

Button, Card, Heading, Text, Hero, Navigation, Footer, Container — 8 components covering everyday page-building needs.
