Fixed-theme reference — always light, no toggle

Penline Light

the always-on light variant

This file hardcodes the light palette directly into :root — there's no prefers-color-scheme query and no data-theme attribute to flip. Drop this stylesheet into a page and it will render light on every device, every time. Its sibling, Penline Dark, is built the same way in reverse.
