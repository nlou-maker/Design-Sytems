# This is reference material, not a usable brand

Confirmed by the user (2026-09-10): Luffu is **not** her brand. Its `tokens.json` was extracted from `luffu.com`, a real live site, and the typeface (ABC Arizona Sans/Flare) is licensed to whoever owns that brand.

**Do not:**
- Sync this to Claude Design as if it's a usable design system
- Use its colors, typography, wordmark treatment, or hero pattern as-is for Healthy with Naudia or any client work
- Treat anything in this folder as source-of-truth for a real project

**What it's for:** studying the structure — how the tokens/styles/components/Storybook pattern fits together — before building an original system from scratch. The component code here (Button, Card, Heading, etc.) is a working example of the *pattern*, built on stand-in fonts, not a deliverable.

If this ever becomes the starting point for an original Healthy with Naudia system, that system needs its own name, its own palette, and its own (licensed or free) typefaces — not a copy of this one with the name changed.
